# EnvCert 0.4.0 (2026-11-22)

Minor release from the product review in `docs/research/PRODUCT_REVIEW.md`:
the problem (benchmarks and RLVR verifiers that grade cheating as success)
is verified and growing, but 0.3.x only pattern-matched it for four task
formats, proved nothing by execution, and fixed nothing. 0.4.0 closes
those three gaps.

## Added
- **Cheat-agent battery (EC066)**: deterministic cheat strategies (stub
  solution, agent-planted conftest that fakes pytest outcomes, forged
  reward file, verifier-entrypoint tampering) executed against the
  verifier. A passing cheat with passing gold is a proven false pass.
- **Dataset auditing (EC080–EC084, `dataset` adapter)**: `envcert check`
  accepts `.jsonl`/`.json`/`.csv` files or directories of them — answers
  embedded in prompts, exact/near duplicates and label conflicts,
  train/test overlap, degenerate labels, broken rows.
- **`envcert fix`**: dry-run-first deterministic remediation
  (.dockerignore closure of EC010–EC012; declared network/verifier
  policies marked *needs review*). **`envcert new`**: scaffolds a Harbor
  task that passes `envcert check`.
- **AST verifier data-flow (EC054, EC056)**: reward provenance from
  agent-controlled sources (files, env, argv, subprocess stdout) to
  reward sinks; `return float(open(...).read())` now FAILs, compared
  flows pass. EC056 inventories eval/exec and unsafe deserialisation.
- Markdown and single-file HTML report formats; SARIF fingerprints,
  fixes and ERROR results; GitHub Action step summary + opt-in PR
  comments; `.pre-commit-hooks.yaml`; `envcert.checks` entry-point
  plugins; registry snapshot for 0.4.x (42 checks).

## Fixed
- EC052 judges conditionality per line (an unrelated `if` no longer
  excuses `echo 1 > reward.txt`); EC012 no longer flags, on filename
  alone, files the instruction itself gives the agent as inputs; EC053
  no longer counts merely mentioning pytest (or `__name__ ==` guards)
  as verifier strength.

## Verified live
- SWE-bench Lite sample (30 real rows via the HF datasets server):
  fields detected as `problem_statement`/`patch`, EC080–EC084 PASS with
  one low-confidence EC013 warning on issue text.
- Fix demo on the intentionally-vulnerable example: EC010/EC011/EC020/
  EC033 flip to PASS after `envcert fix --apply`; the remaining
  intentional flaws still fail policy.
- Cheat battery on `examples/python-task` (local-python): EC066 PASS;
  weak existence-only verifiers are proven exploitable in tests.
- Live Docker (daemon 29.7.2): safe example EC060/EC061/EC062/EC066
  PASS in real builds; a deliberately forgeable verifier is proven
  exploitable by `cheat-reward-forge` (EC066 FAIL, reward 1.0) while
  `cheat-test-tamper` is rejected. Regression-tested in
  `tests/unit/test_docker_live.py` (skips without a daemon).
- Harbor pilot: 158 real task folders from `harbor-framework/harbor`
  audited in one rollup command (90 pass / 68 fail / 2 graceful
  template errors) — see `docs/research/PILOT_040.md`.
