# Envicert 0.3.2 (2026-11-22)

Patch release from a second end-to-end review, this time run against the
published 0.3.1 artifact in a clean environment (no pytest, no dev sources).

## Fixed
- **False PASS when the verifier never ran**: with `pytest` absent, the
  local-python runner turned "No module named pytest" into reward 0.0, so
  EC060 said "verifier broken" while EC061 ("no-op rejected") and EC062
  ("outcome is repeatable") reported PASS. The runner now detects the missing
  dependency up front; EC060–EC064 return ERROR when execution itself fails,
  and mutants that cannot be executed are no longer counted as verifier
  rejections (EC063/EC064).
- **Self-asserted baseline suppression**: a report could mark its own failing
  findings `baseline_suppressed` and claim a passing policy without showing a
  baseline. `verify`/`attest` now recompute suppression from the baseline
  report (`--baseline`); unbacked suppression is rejected with exit 2.
- **0.1.x/0.2.x reports rejected by the 0.3.1 validator**: summary counters
  those versions never wrote are no longer required of them (reports from
  0.3.0+ are still strictly checked). The report schema remains 1.0.0.

## Added
- `envicert verify --recheck --task <dir>` re-runs the report's static checks
  and compares the findings, detecting reports whose findings were dropped
  or added after generation.
- `envicert verify --fail-on <severities>` evaluates policy under the
  consumer's own threshold instead of the report's self-asserted `fail_on`.
- `envicert verify` output now states plainly that checks are not re-run
  unless `--recheck` is given.

## Verified live
- Clean-venv install of the published package: missing-pytest runs return
  ERROR for EC060–EC063 instead of false PASSes.
- Tamper matrix re-run against the new build: forged policy/summary, forged
  suppression, dropped findings (with `--recheck`), weakened `fail_on` (with
  `--fail-on`) all detected; signed attestation round-trip still verifies,
  real DSSE payload tampering still fails.
- Reports generated by Envicert 0.1.0, 0.2.0 and 0.3.0 all verify.
- Full suite, ruff and mypy clean.
