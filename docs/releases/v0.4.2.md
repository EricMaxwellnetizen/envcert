# Envicert 0.4.2 (2026-11-23)

Patch release from the first red CI runs of 0.4.1 — the matrix doing
its job on code that was green on the maintainer's machine.

## Fixed
- **EC054 validated-variable propagation**: `reward = grade(state)`
  followed by `return reward` produced a validated assignment hit and
  an unvalidated return hit; validation now propagates through the
  variable. Regression test: `test_ec054_grading_helper_result_is_validated`.
- **Docker runner on Windows-containers engines**: GitHub's
  windows-latest runners expose a Docker daemon for Windows containers.
  `DockerRunner.info()` claimed availability, the Linux image build
  then failed, and EC060/EC066 reported ERROR. Availability now probes
  `{{.Server.Os}}` and requires Linux containers; other engines report
  unavailable with the reason, and live tests skip cleanly.
- Docs workflow used two invalid action SHAs (job failed at setup);
  corrected, site deploys to GitHub Pages.

## Verified live
- Local: full suite green (incl. live Docker with the OS probe:
  `docker daemon 29.7.2 (linux)`).
- GitHub after push: CI (9-job matrix), Security, Release, Docs.
