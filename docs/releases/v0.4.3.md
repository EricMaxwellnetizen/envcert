# Envicert 0.4.3 (2026-11-23)

Patch release from the scale campaign in
`docs/research/PILOT_SCALE.md`: 723 real task bundles (Harbor Hub,
Terminal-Bench, Harbor templates), the full 2,294-row SWE-bench test
split, SWE-bench Lite, and 131 inspect_evals packages — with every
policy-driving finding class hand-reviewed and the failures fixed.

## Fixed
- **Dataset truncation (the important one)**: dataset files were read
  through the 2MB bundle-text cap, so a 2,294-row JSONL silently
  audited only its first 57 rows. The loader streams from disk now;
  the full split audits in ~2s. Regression-tested past the cap.
- **Analysis caching**: EC052/EC053/EC054/EC056 share one AST analysis
  per run (cad-bench 208s → 51s, byte-identical findings).
- **Inspect adapter** analyses sibling scorer modules (fewer
  assertion-free false alarms across inspect_evals).
- **EC023** component-exact chmod targets (`/testbed` ≠ `/tests`);
  **EC032** version-pinned installer URLs are MEDIUM, unversioned
  stay HIGH.
