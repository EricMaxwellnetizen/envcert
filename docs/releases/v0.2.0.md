# Envicert 0.2.0 (2026-11-22)

Implements the full roadmap deferred from 0.1.0.

## Added
- Adapters: NeMo Gym (`dataset.toml`/`verifier.py`/JSONL rows) and Inspect
  AI (`@task` files, scorer detection). Adapter list is now
  harbor / generic / nemo-gym / inspect (auto-detected in that order).
- EC004 multi-step auditing (per-step instruction + verifier completeness,
  per-step instruction quality in EC002).
- Docker dynamic controls: EC061 no-op negative control and EC062 gold
  repeatability under `--execution docker`; shell-solution mutation EC064
  under `--mutation --execution docker`.
- OCI image digests: `--image`/`--image-digest`, automatic capture from
  Docker builds into `environment.image_digest`, OCI subject in in-toto
  attestations.
- Cosign OCI flow: `envicert attest --image name@sha256:...` (mutable
  references refused), new `envicert verify-attestation` command, CUE/Rego
  policy examples.
- External runner protocol (`--execution external --runner-command`) for
  disposable-VM/remote sandbox providers.
- Companion tools: `--external-tools` → Hadolint/Trivy/Semgrep as
  EC070–EC072 (NOT_RUN when a tool is absent; Hadolint info/style notes do
  not fail policy).
- Richer Python mutation operators (BoolOp, AugAssign, UnaryOp, string
  constants) and print/logging-only possible-equivalent tagging.
- Examples: `nemo-gym-dataset`, `inspect-eval`, `multistep-task`,
  `cosign/` policies.

33 checks total (was 28). Report schema stays 1.0.0 (additive fields only:
`environment.image_digest` was already specified; `image_reference` added).

## Verified
- pytest suite green; Docker EC060/EC061/EC062/EC064 run live against
  Docker 29.7.2 with reward 1.0/0.0 outcomes as expected; Hadolint 2.12
  executed live via EC070.
