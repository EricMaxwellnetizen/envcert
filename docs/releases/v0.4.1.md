# EnvCert 0.4.1 (2026-11-23)

Patch release focused on analysis precision and project surface.

## Added
- Inter-procedural validation in EC054: a reward flowing through a
  local helper that itself compares/asserts is now recognised as
  validated instead of WARN (the automationbench/grade.py shape).
  Parse-only helpers remain FAIL: factoring a parse into a function
  does not validate it.
- EC056 JavaScript/TypeScript verifier patterns (`eval(`, `new
  Function`, `vm.runIn*`, template-literal `exec(`).
- MkDocs Material documentation site (GitHub Pages workflow), PyPI/CI
  badges, real generated demo reports under `docs/demo/`.
- Six roadmap issues filed (#1–#6): call-graph reward provenance,
  semantic dedup, NeMo HTTP probing, compose/prebuilt execution,
  JS/TS mutation, Harbor Hub listing.

## Verified live
- Terminal-Bench pilot re-run: 47/51 tasks pass policy, unchanged from
  0.4.0, with EC054 drivers reduced to the two known inter-procedural
  review items.
- Docs site builds under `mkdocs build --strict` (demo and release
  pages included in nav).
- Full test suite, ruff, mypy (counts in the release commit).
