# EnvCert 0.4.5 (2026-11-23)

Roadmap completion release: all four implementable issues (#1–#5) land,
plus the operator-facing industry-readiness checklist.

## Added

- **Compose-project execution** (issue #4, rest): Harbor tasks whose
  environment is `environment/docker-compose.yaml|yml` now run the gold,
  no-op, repeatability and cheat-battery checks. A generated override
  merges `cap_drop: [ALL]`, `no-new-privileges`, `mem_limit: 2g`,
  `cpus: 2`, `pids_limit: 256` into every service; with network none the
  project's default network is marked `internal`, so services can talk to
  each other but cannot egress. The project is torn down afterwards.
- **Cross-module EC054 summaries** (issue #1, complete): validation and
  agent-data-return summaries now resolve through imports
  (`from helpers import compare_deep`, `import helpers as h`), so
  `grader.py -> compare.py` pipelines validate while unvalidated chains
  stay flagged.
- **NeMo Gym HTTP Resources-Server probing** (issue #3): opt-in
  `--nemo-endpoint` (or `[checks.nemo] endpoint`) POSTs
  `{"response": ..., "task_data": row}` for gold, mutated and
  row-swapped answers. Bounded to 10 rows, a wall-clock budget and
  1 MB responses; headers configurable and never echoed into evidence.
- **Deterministic semantic near-duplicates in EC081** (issue #2):
  token-set cosine (>= 0.82) over discriminative content tokens, bounded
  sample; catches reordered/lightly reworded prompts that 5-gram
  Jaccard misses. Conflicting labels on a semantic pair escalate to
  HIGH. Stdlib only. Validated on 40 real SWE-bench prompts that were
  deterministically paraphrased (44 pairs found, 0 false positives on
  40 untouched distractors).
- **JS/TS solution mutation in EC063** (issue #5): a comment/string/
  regex-aware lexer mutates string contents, numbers, booleans and
  comparison/arithmetic/logical operators in `solution/*.js|.mjs|.cjs|
  .ts`; task tests run under `node` (`tsx`/`ts-node` for TypeScript when
  installed). Invalid mutants are excluded from the rejection rate.
- **docs/research/INDUSTRY_READINESS.md**: deployment envelope,
  proven-at-scale evidence, guarantees vs limits, adoption checklist,
  operational costs and the release-integrity checklist.

## Fixed

- EC065's local probe result summarisation was shared with HTTP mode and
  now records `runner` in evidence so consumers can tell which transport
  produced a verdict.
- Performance: the cross-module summary engine no longer re-walks the
  AST for every assignment and fixed-point iteration (cad-bench 113s ->
  67s); the semantic near-duplicate pass no longer re-normalises every
  candidate pair's prompts (full SWE-bench audit 19s -> ~5s).
- A grader that raises or returns an HTTP error for a wrong answer now
  counts as "no reward awarded" (a rejection) instead of an inconclusive
  probe; transport failures stay inconclusive and are reported as such.
- Ruff/mypy findings in the new modules; no behaviour change.

## Verified

- New unit tests: fake HTTP Resources Server (gold/mutant/swap + header
  secrecy), semantic duplicate/clean pairs, JS mutation sites and a
  node-executed EC063 PASS, compose fake-daemon hardening assertions,
  plus the live compose test under a real daemon.
- Full suite green with the 80% coverage gate; ruff and mypy clean.

## Remaining

- Issue #6 (framework listings, external adoption) is outreach, not a
  code gap. Embedding-level dedup and hosted dashboards stay
  evidence-gated (see `docs/architecture/ROADMAP.md`).
