# EnvCert 0.1.0 (release candidate, prepared 2026-11-22)

First public-release candidate. **Not yet published**: no tag, PyPI upload or
GitHub release has been performed from this workspace (see
RELEASE_READINESS.md for the exact remaining steps).

## Highlights
- Deterministic offline static checks (24) for Harbor task directories with
  stable IDs EC001–EC054, plus opt-in dynamic (EC060–EC062) and mutation
  (EC063) checks.
- JSON report (schema 1.0.0) / text / SARIF output, policy exit codes,
  profiles and `envcert.toml`.
- in-toto Test Result attestations (optional Cosign signing), report
  verification by schema + bundle digest.
- Composite GitHub Action; examples with locked expected findings.

## Known limitations
- Docker dynamic mode needs a Docker daemon (verified live against Docker
  29.7.2 on 2026-11-22: gold run captures reward 1.0).
- Example base-image digests were pinned to the real `python:3.12-slim`
  digest current on 2026-11-22; refresh them when rebasing the examples.
- NeMo Gym / Inspect adapters, OCI image subjects and docker negative
  controls are roadmap items, not in this release.
