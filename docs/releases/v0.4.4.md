# Envicert 0.4.4 (2026-11-23)

Roadmap release: two of the filed GitHub issues land.

## Added
- **Prebuilt-image Docker execution** (issue #4, part): a Harbor task
  that declares `[environment] docker_image` and ships no Dockerfile
  now executes dynamically — the image is pulled and used as-is for
  gold (EC060), no-op (EC061), repeatability (EC062) and the cheat
  battery (EC066), under the same restricted runner. Locally built
  images are unchanged (and still cleaned up; prebuilt images are
  never removed).
- **Transitive validation in EC054** (issue #1, core): validation now
  propagates through helper call chains — if the function that touches
  agent data delegates to a helper that compares/asserts, the flow is
  validated. Chains with no comparison anywhere remain flagged.

## Verified live
- New live test: a `docker_image`-only task (digest-pinned
  python:3.12-slim, shell verifier) passes EC060/EC061/EC066 under the
  real daemon, alongside the existing build-path and forge-proof
  tests (`tests/unit/test_docker_live.py`, skips without a daemon).
- Fake-daemon unit tests assert the prebuilt path pulls, never
  builds, and never removes the image.

## Remaining on the roadmap
Compose-service execution (rest of #4), NeMo HTTP probing (#3),
semantic dedup (#2), JS/TS mutation (#5), Hub listing (#6).
