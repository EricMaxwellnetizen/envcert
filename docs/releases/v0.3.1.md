# Envicert 0.3.1 (2026-11-22)

Patch release fixing integrity and safety defects found in an end-to-end
review of 0.3.0 (real CLI runs against every example adapter, live Docker,
local-python, NeMo probing, mutation, attestations, tamper tests, packaging).

## Fixed
- **Report forgery**: `verify`/`attest` recompute `policy.passed` and all
  summary counters from the findings. A forged `passed=true` or edited counts
  are now rejected (exit 2); `verify` uses exit 1 only for a genuine
  bundle-digest mismatch with `--task`.
- **Unsigned attestation success**: `verify-attestation` fails on unsigned
  statements/DSSE envelopes unless `--allow-unsigned` (structural only).
  Detached `.sig` files from `--sign` are verified via `cosign verify-blob`.
- **Silent signing failures**: `attest --sign`/`--image` exit 3 when the
  requested signing/OCI attestation did not happen. `attest --image` refuses
  a digest that disagrees with the report.
- **Image digest binding**: `--image` prefers the registry `RepoDigests`
  manifest digest over the local image ID (ID fallback is labelled);
  unresolvable refs and malformed digests are errors (exit 2).
- **Windows runner commands**: backslash paths in `--runner-command` work
  unquoted; quoted paths with spaces still work.
- **Vacuous passes**: unknown check IDs, empty `[checks] enabled`, and
  configurations selecting no checks are rejected.
- **Implicit unsandboxed execution**: `[checks.dynamic] enabled = true`
  requires an explicit execution mode.
- **Baseline hiding**: suppression fingerprints finding content, so a new
  issue at the same path/line is not suppressed by an old baseline.
- **Digest honesty**: file-listing truncation (>5000 files) and unreadable
  files are reported in warnings instead of silently hashed as empty.
- Docker check images use unique per-run tags (no concurrent-run collisions).

Report schema remains 1.0.0; 0.3.0 reports still verify.

## Verified live
- Full suite, ruff, mypy clean; coverage 78%.
- Tamper matrix: forged policy/summary → exit 2; forged report attestation
  refused; unsigned DSSE verify → exit 1, `--allow-unsigned` → exit 0
  (labelled non-cryptographic); cosign `--sign` + `verify-attestation`
  detached-signature round-trip passes, tampered payload fails.
- Real Docker image digest resolution against `python:3.12-slim` and a local
  registry image returns the `RepoDigests` manifest digest.
