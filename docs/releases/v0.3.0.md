# EnvCert 0.3.0 (2026-11-22)

Implements the 0.3 roadmap.

## Added
- **NeMo verifier probing (EC065)**: under `--execution local-python`,
  `verify()` is fed each row's expected answer (gold), a mutated answer and
  a row-swapped answer in a subprocess; correct must pass, wrong must fail.
- **Dataset rollups**: `envcert check <dataset> --dataset` runs every task
  folder beneath a dataset root and aggregates per-task policy (no dataset
  score). Example: `examples/dataset-rollup`.
- **Inspect scorer strength (EC055)**: substring (`includes`) and
  model-graded scorer weakness/reproducibility warnings.
- **Inspect dynamic runner example**: `examples/external-runners/inspect_runner.py`
  implements the external-runner protocol over `inspect eval`.
- **Coverage-aware mutation (EC063)**: mutants on lines the gold run never
  executes (coverage.py) are `uncovered-inconclusive` and excluded from the
  rejection rate; verifier-input mutation is covered by EC065.
- **Baselines & diffing**: `--baseline old.json` marks identical findings
  `baseline_suppressed`, excludes them from policy, and emits SARIF
  `suppressions`; new `envcert diff old.json new.json [--strict]`.
- **Registry attestation flows**: keyless GHCR Cosign workflow example
  (`examples/github-actions/attest-oci.yml`).

35 checks total. Report schema remains 1.0.0 (additive `baseline_suppressed`).

## Verified live
- EC065 probing passes the NeMo example and flags an always-1.0 verifier.
- Cosign round-trip against a local OCI registry: image built and pushed,
  `envcert attest --image <name@sha256:...>` attached the attestation, and
  `envcert verify-attestation --policy examples/cosign/policy.cue` passed.
- Rollup over the demo dataset: 1/2 tasks pass (the intentionally weak one
  fails), exit 1.
